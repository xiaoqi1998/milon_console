## 部署脚本修正（1Panel 计划任务）

用户提供的自动部署脚本有 2 个致命 bug，已修正：
1. **编译判断恒真**：`git pull` 之后再比较 HEAD 与 origin/main 必然相等 → 永远 exit 0 不部署。修正：pull 前记录 `BEFORE`，pull 后对比。
2. **`docker compose restart` 不重建镜像**：Dockerfile 多阶段构建、compose 未挂载宿主机二进制，restart 复用旧镜像旧代码。修正：`docker compose up -d --build`。
3. 次要：宿主机 `go build` 多余（多阶段在容器内编译）；`find $LOG_FILE -mtime +7 -delete` 对单文件轮转无意义，改为按天轮转日志 + find 目录清理。

项目部署环境：`/opt/milon/milon_console`，`docker compose` 构建 `milon-api-server:latest`，监听 8080，健康检查 `/api/health`。
