MCP 接入

本服务内置 MCP（Model Context Protocol）端点 /mcp，把全部 REST 能力映射为 57 个 MCP 工具。AI 编程代理接入后，可直接用自然语言驱动链上操作：账户与密钥、代币转账、合约读写、交易解析、DID / VC / SFT 全生命周期——无需写一行 REST 调用代码。工具与 REST 端点一一对应、行为完全一致。

把下面的 JSON 加入 ZCode / Claude Code 的 MCP 配置（mcpServers 字段）。URL 端口跟随当前页面访问地址自动生成。

注意事项：MCP 端点单次工具调用回环超时 120s（长任务如 sft_flow / vc_flow 请耐心等待）；开启 ENABLE_BODY_LOG 时 /mcp 工具入参（含私钥字段）会写入日志，仅限 devNet 调试，生产勿开；对外暴露服务务必设置 MCP_AUTH_TOKEN。多网络并存时可对 /mcp 请求携带 X-Milon-Network 头（客户端在 mcpServers 配置的 headers 中设置，如 {"X-Milon-Network": "devNet"}），全部工具调用按该网络执行，缺省走服务端默认网络。

快速上手

接入成功后，直接对 AI 说这些话试试（按场景从易到难）：

  • 网络「当前连的是哪个网络？查一下最新区块头」
  • 账户「生成一个 ed25519 新账户，然后去领水」
  • 转账「查我的余额，把 500 MIL 转到 目标地址，等确认后给我 txHash」
  • 合约「用 idl_metadata 看看 token app 有哪些方法，然后帮我查这个地址的 MIL 余额」
  • DID「给我创建一个 DID，别名绑成 alice，再加一个服务端点」
  • 编排「跑一遍 SFT 全流程：建 SFT、建 slot、mint 100 份给我」
  • 排错「这笔交易 0x… 卡住没确认，帮我解析一下它的内容和事件」
