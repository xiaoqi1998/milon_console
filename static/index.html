MCP 接入

本服务内置 MCP（Model Context Protocol）端点 /mcp，把全部 REST 能力映射为 64 个 MCP 工具。AI 编程代理接入后，可直接用自然语言驱动链上操作：账户与密钥、代币转账、合约读写、交易解析、DID / VC / SFT 全生命周期——无需写一行 REST 调用代码。工具与 REST 端点一一对应、行为完全一致。

配置操作账户（可选）

把操作账户常驻在 MCP 客户端配置里（headers.X-Milon-Accounts，值为 base64(JSON 数组)，上限 64 条），之后全部写工具只传地址、免传私钥：contract_write / transfer_mil（传 fromAddress）/ faucet_claim / DID / SFT / VC / 保存指令执行——私钥缺省时按地址自动引用配置账户，显式传私钥仍优先。服务端零持久化（账户只随单请求过境，多用户共用一台服务互不串）；该头等同于持有私钥的通道——能带此头即能签名，请像保管私钥一样保管客户端配置文件。

参数说明
字段必填说明
name否展示名，account_config_list 回显用
address是base58 地址；数组内不可重复
privateKey是hex 或 base58 私钥
keyType否secp256k1（缺省）/ ed25519 / bls12381 / fndsa512
publicKeyfndsa512 必填抗量子曲线公钥无法从私钥派生，必须显式携带（account_generate 返回里有，897 字节）；其他曲线可省，服务端派生并校验与地址、私钥的配对

配置有误时所有请求返回 400，错误定位到具体条目（如 X-Milon-Accounts[0]: privateKey 与 publicKey 不配对）。用下方生成器粘贴账户数组，本地完成 base64 编码（私钥不发送到服务端），直接得到可粘贴的完整配置：

也可用命令行生成 base64（输出粘贴到 headers 的值里）：

# bash（-n 去尾换行，-w0 不折行）
echo -n '[{"name":"main","address":"<地址>","privateKey":"<私钥>"}]' | base64 -w0
# PowerShell
[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('[{"name":"main","address":"<地址>","privateKey":"<私钥>"}]'))

安全边界：账户头随每个请求过境，服务端不落盘、不跨请求共享、不进日志（ENABLE_BODY_LOG 记录的是请求体，不含该头）。account_config_list 工具可随时核对自己已配置的账户（脱敏回显，永不返回私钥）。

注意事项：MCP 端点单次工具调用回环超时 120s（长任务如 sft_flow / vc_flow 请耐心等待）；开启 ENABLE_BODY_LOG 时 /mcp 工具入参（含私钥字段）会写入日志，仅限 devNet 调试，生产勿开；对外暴露服务务必设置 MCP_AUTH_TOKEN。多网络并存时可对 /mcp 请求携带 X-Milon-Network 头（客户端在 mcpServers 配置的 headers 中设置，如 {"X-Milon-Network": "devNet"}），全部工具调用按该网络执行，缺省走服务端默认网络。
